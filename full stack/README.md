# Thiranex - Full-Stack Deployment & Project Architecture

## 📌 Project Overview
This project is a responsive assignment webpage developed as part of the Thiranex Skill Development Program. It represents Assignment 5: Full-Stack Deployment & Project Architecture.

## 🚀 Technologies Used
- HTML5 – Structure of the webpage
- CSS3 – Styling and responsive design
- JavaScript – Interactive functionality

## ✨ Features
- Responsive website design
- Thiranex-style header and navigation menu
- Assignment details and availability status
- Due date and remaining days display
- Watch Task Tutorial button
- Key features and expected outcome sections
- Refresh page functionality
- Interactive navigation menu
- Submit Work button

## 📂 Project Structure
```text
Thiranex-Full-Stack-Deployment/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## 🛠️ How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html`.
4. Run using the Live Server extension.
5. View the website in your browser.

## 🎯 Project Objective
To develop a responsive and interactive webpage using HTML, CSS, and JavaScript while understanding frontend architecture and web development concepts.
